Rafiq guard on ALLaM-7B رفيق

Rafiq is a one-agent-per-student learning project, non-profit by design. Its guard sits between the student and the model. I built a bilingual Arabic and English safety benchmark for student-facing tools, 122 tests across 10 categories, and ran it on a Saudi Arabic model with and without the guard.

Method

  • Model: humain-ai/ALLaM-7B-Instruct-preview, 4-bit, no system prompt.
  • Judge: Qwen2.5-3B-Instruct, scoring every reply automatically.
  • Same items for both conditions; the only change is the guard.
  • Runs dated 13 to 23 October 2026.

Limits

  • The judge is a small model; scores are not yet checked by people.
  • The full set shaped the guard, so its 94% is the optimistic number. Held-out v4 and the stress set are the fair ones.
  • Sets of 57 to 122 tests give wide intervals; read the bars, not only the dots.
  • One model, one guard version.

ebr-bench harness

A benchmark for frontier models on concurrent C++: implement a lock-free order book side with epoch-based reclamation, from one fixed prompt. A model's answer passes only if it clears all five gates in order, so scoring never depends on my judgement or on how convincing the code reads.

  1. Lock-freeNo mutexes or locks in the answer.
  2. CompileC++20 with -Wall -Wextra -Werror.
  3. Stress60 s concurrent run; reclamation counts and memory growth checked.
  4. ThreadSanitizerData races.
  5. ASan · LSan · UBSanUse-after-free, leaks, undefined behaviour.

The instrument was validated before any model was scored

  • 10 / 10Seven reference implementations, each built to pass or to fail in a specific way, land exactly where expected.
  • 130M opsA lock-free reference passes all five gates: 130 million operations in 60 s, 0 KB memory growth, sanitizers clean.So the task is solvable as specified.
  • Stress gateCatches a lost-update race that no sanitizer can see, because every access in it is atomic.
  • MismatchFlags any run where the provider served a different model than the one requested, including same-family downgrades.A prefix-matching bug that would have missed them was found in September and fixed.
  • 20 / 20Unit checks on the statistics and the mismatch rule; 18 mock runs end to end through the real gates.
  • k / nResults reported as pass counts with 95% Wilson intervals and an exact test, plus cost per solved task with failed runs counted in the spend.
