Built from the spec 04 · QR decoder · Spec to working code

When the reader fails, rebuild the reader.

A standard reader decoded one of two codes and refused the other. Instead of trying another app, I rebuilt decoding from the QR specification: find the grid, recover the format bits, unmask, read the zig-zag, then repair it with Reed–Solomon error correction.

  1. Locate the finders
  2. Read the format bits
  3. Remove the mask
  4. Read the zig-zag
  5. Reed–Solomon repair
  6. Output
 
2/2Codes read exactly: version 10, 57×57 modules, zero symbols needing correction
The standard OpenCV reader read 1 of the 2. The panel runs a browser port of the same pipeline on this page's own code, live.
